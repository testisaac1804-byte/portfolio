1. 這是什麼網站？

這是一個架設在 solve.quest（解謎任務工作室）平台上的互動解謎遊戲，偽裝成一個 2003 年的台灣國小網站（嘉平縣溪埕鎮溪埕國小）。

整個網站是一層一層的謎題盒：表面是普通的舊校網，但藏在 HTML 註解、錯誤頁面、備份目錄裡的全是故事線索。解謎者要像偵探一樣，從蛛絲馬跡拼出真相。

官方一共放了兩條任務線：

  • 《溪埕國民小學失蹤事件》 — 2003 年女學生許雅雯「失蹤案」背後的真相（28 章小說）
  • 《雅玲的日記》 — 六年乙班張雅玲的日記（24 章），是第二條任務線，也是第一條的隱藏視角

網站由單一創作者/小團隊製作：域名約 US$10–30/年（Porkbun 註冊），託管在 Vercel 免費方案，其餘全部是免費工具 —— 真正的成本是數百小時的寫作與設計。

2. 網址的騙術（DNS 技巧）

網址 www.hces.edu.tw.solve.quest 是整個體驗的第一個謎題。DNS 是由右往左讀的：

www.hces.edu.tw.solve.quest └────────┬────────┘ └──┬──┘ 子網域（假裝是學校） 真正的域名 "www.hces.edu.tw" = "solve.quest"
  • 真正的域名是 solve.quest（2025-08-25 於 Porkbun 註冊）
  • www.hces.edu.tw 只是子網域的名字 —— 創作者故意把它命名得像一所台灣學校（hces.edu.tw 是台灣教育部的域名格式），讓眼睛一掃過去以為是真的學校網站
  • DNS：www.hces.edu.tw.solve.quest → 76.76.21.21（Vercel 邊緣節點）
  • 主站 solve.quest 走 Cloudflare（172.67.130.62 / 104.21.3.48）
💡 教訓：看到網址先拆解。後綴（TLD）往左數第二段才是真正的域名，前面全部可以是偽裝。

3. 故事摘要（兩條任務線）

《溪埕國民小學失蹤事件》

2003 年 7 月 4 日，三年丙班學生許雅雯在「白沙嶺親山徑校外教學」時失蹤。官方說法：她走失在山區。警消在山上搜了三天，學校貼協尋公告，家長焦急等待。表面故事到此為止。

但網站的隱藏資料說的是另一個故事：

  • 當天 17:00 起，學校電腦 PC-OLD-03 出現長達 5 天的搜尋紀錄（361 筆）——「老師在哪」「我不是故意沒有去」「我只是去廁所」「我在學校不是山」「門打不開」「標叔叔救我」「媽媽找我」
  • 真相：雅雯去上廁所，回來時車隊已經開走。她獨自走回學校，躲進電腦教室後方的弱電間（沒人會注意的小設備室）等媽媽——然後門被鎖上，沒人知道她在裡面
  • 她在裡面待了 5 天（7/4 → 7/9），用一台舊電腦拼命打字求救，最後印出一張「我想回家」的紙，但mail server unreachable，沒有寄出去
  • 9 月開學後，校方一連串「正常」公告其實是善後：9/12「消毒」（聞到異味請通知總務處）、9/13 資訊組「設備盤點」（實際上是把證據搬進備份目錄）、9/15「北側校舍暫停使用」（封鎖現場）、9/18「請同學勿散播未經證實消息」
  • 2006 年，鎖門的校工吳清標（標叔叔）死於租屋處，生前酒後說過「門後面有人」「我不知道」
  • 2026 年，北側舊翼樓拆除——真相即將被抹去，小說的主角（舊生）把一切寫成手記發布

《雅玲的日記》

張雅玲是六年乙班的學生，教過雅雯騎腳踏車，也是少數知道雅雯「祕密基地」（工友室後方 + 電腦教室後方）的人。她的日記表面是平凡的國小生活——媽媽、吹風機、交換禮物、冬至湯圓——但 12 月 22 日起，媽媽因為頭痛開始「一直睡」。

雅玲用一個 12 歲孩子能想到的所有方式假裝一切正常：偽造聯絡簿簽名、洗碗想蓋過味道、跟老師說「媽媽只是頭痛」。12 月 26 日，老師堅持送她回家，才發現媽媽已經走了（腦血管破裂）。日記最後一句：「我再也不會聽到媽媽說『後面還沒乾』了。」

💡 兩條任務線互相鏡像：兩個女孩、兩扇鎖著的門、兩種沒人聽見的沉默。雅玲的日記同時解釋了為什麼她在第一條線裡「記憶不穩」、不願多談。

5. HTTP 狀態碼全解析（403 / 404 / 200 是什麼）

你訪問網站時，伺服器會回一個「狀態碼」告訴你結果。這個網站把狀態碼當成解謎工具用 —— 有些 403/404 是真的（檔案不存在），有些是故意放的謎題提示。

狀態碼一般意思在這個網站上的意義
200 OK 成功。檔案存在且已送出 正常頁面。但別太相信 200——有些 200 頁面本身就是謎題（例如「找不到指定檔案」的錯誤頁其實回傳 200，裡面藏了下一條路徑）
301/302 Redirect 頁面搬家，瀏覽器自動跳到新位置 本網站幾乎不用，全部是靜態檔
403 Forbidden 「你沒有權限看這個」——檔案存在但不給你 最重要的一種。本網站的 403 頁是精心設計的謎題：
• 會寫出檔名被隱藏的日期（set hidden 2003/09/13 18:44）
• 常附「原始檔」連結（_v/...）洩漏更多
• 暗示資料搬去了備份目錄
看到 403 = 你正走在對的路上。
404 Not Found 「沒有這個檔案」 通常是真·不存在。但有例外：
• 某些「404」其實是故意留的（例如相簿裡被刪掉的照片編號）
• 有些頁面表面上 404，其實是叫你從錯誤訊息裡找線索（例：work_0197.html 回傳 200 但內容是「找不到指定檔案」，並洩漏 /student_work/920704/3c/hsu_yw_tmp.html）
403 on /cgi-bin/, /wp-admin/ 一般網站：真的拒絕存取 這裡是道具——回傳的是一個固定的靜態假 403 頁（59 bytes），沒有任何 CGI 真的存在。騙你以為是 2003 年的老網站有 CGI 程式
200 /backup/0913/student_work/920704/3c/ 成功 這是唯一的目錄列表（Index of ...），直接把她的作文檔名列出來 —— 全站最重要的一頁

速查口訣

  • 200 = 檔案在 → 看內容
  • 403 = 檔案在但被藏 → 讀 403 頁上的字，它會告訴你去哪
  • 404 = 通常真的沒有 → 但檢查回應內容，可能有線索頁面
  • 看到 set hidden / move tmp to / backup/0913 這些字 = 下一條路

7. 如何找到所有秘密（逐步攻略）

這是完整的解謎流程，從零開始，照做就能解開全站：

1
逛表面網站。打開首頁，看公告、留言板、作品區。注意 notice_920704.html（協尋公告）。
線索：訪客計數器顯示 0000913 —— 這不是人數，是日期暗示（9/13）。
2
點許雅雯的作品（works.html → 三年丙班 0197）。它不會正常打開 —— 出現「找不到指定檔案」，路徑是 /student_work/920704/3c/hsu_yw_tmp.html。記住 920704（= 她失蹤那天）和 tmp（暫存檔）。
3
瀏覽器開「原始碼」檢視（或找「原始檔」連結）。所有頁面的 HTML 註解 <!-- ... --> 都是線索：
guestbook.html: <!-- 1742 move private 0913: /backup/0913/guestbook/1742.html --> notice_920704.html: <!-- 920913 掃描圖下方手寫補註不用重掃。公告本身可以留。 --> index.html: <!-- 920913 資料搬移後首頁不要刪。公開頁只保留公告與相簿。 -->

11. 網站怎麼做出「2003 年」的感覺

整站是純靜態檔案（HTML + CSS + JS），沒有任何後端。所有「2003 年老網站」的效果都是刻意做的：

效果技術
圖片一格一格慢慢載入（像撥接）imgload.js：圖片藏在 data-img-src，載入時用 CSS clip-path 做「下載進度」動畫，隨機跳動
整頁慢慢出現（像慢網路）slow-stream-sw.js：Service Worker 攔截 HTML 請求，把回應切成小塊，用隨機延遲重新串流
點連結有延遲imgload.js 攔截點擊事件，隨機延遲 360–650ms 才跳頁
頁面底部灰色小字「本網站內容為虛構創作」JS 自動插入（addFictionNotice()）
「CGI 程式」/cgi-bin/假的。回傳固定 59-byte 靜態 403 頁
訪客計數器 0000913不是人數，是日期密碼（9/13）
班級登入頁靜態表單，POST 只會重刷同一頁

託管：Vercel（免費方案，自動 HTTPS + CDN），主站套 Cloudflare。域名 Porkbun 註冊，.quest 後綴。總成本約 US$10–30/年。
