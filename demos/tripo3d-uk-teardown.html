Investigation · 2026-10-21 live third-party reseller tripo3d.uk not affiliated with Tripo

Somebody else's 3D model, your prepaid credits

tripo3d.uk is not Tripo. It is a Nuxt re-skin of Tripo's own Studio app, served from an nginx box in front of Cloudflare, that bills users in its own "积分" (credits) and settles every generation through a pool of borrowed official Tripo API keys. There is no model, no inference and no payment gateway of its own — the business is the spread between what Tripo charges per API call and what a user pays per credit, plus a wholesale layer underneath it.

02 · The product is Tripo's app, re-skinned

The shell is a stock Nuxt 3 build: an empty <div id="__nuxt">, a window.__NUXT__ config with apiBase:"" (so every call goes to the same origin — no upstream host is exposed), and 33 preload/prefetch hints naming 22 JS and 12 CSS files. Pulling the chunks and grepping the route table gives the whole shape of the product without ever logging in:

/ /login /register /workspace/generate /workspace/image /workspace/fill-parts /workspace/retopology /workspace/rigging /workspace/segmentation /workspace/smart-segment /workspace/texture /workspace/texture-edit /workspace/texture-pbr /workspace/texture-upscale /admin /admin/users /admin/keys /admin/batch-keys /admin/logs /admin/subservers /admin/models /admin/config

Those workspaces are Tripo Studio's feature set mapped one-to-one — generate, image, fill-parts, retopology, rigging, segmentation, smart-segment, texture, texture-edit, texture-PBR, texture-upscale. The interesting half is the second block: eight /admin routes — a hub plus seven screens — that no customer ever sees, and they are the business.

The copy, running

This is the same build, re-served from this domain with the network cut. The one file I wrote answers /api/announcement with the body captured from the origin (that notice is the operator's own text, nothing here is my paraphrase) and fabricates the rest of the surface: fetch, XHR, WebSocket and service-worker registration are blocked, and every address it stopped is logged in window.__mirrorBlocked.

The login is part of the fabrication. Any username and any password are accepted — the guard answers /api/auth/login locally, so the workspace renders with 128 credits that are a constant in mirror-guard.js, not an account. That is the point: the paid screens are what the teardown is describing, and you cannot see them on the real site without an account the operator sells.

A submitted job is a demo too: the guard keeps a timestamp, reports a rising percentage for seven seconds, then puts a Khronos sample model on the stage — the duck, labelled DEMO — so the viewer, the material presets and the export buttons can be used. Nothing was generated from your picture and nothing was sent anywhere; the same local .glb is what 导出 hands back.

Type anything into the two fields and you are in — that is the demo, not a hole in their auth: the credential check never leaves this page. Upload a picture, press 生成模型, and seven seconds later the stage loads the sample model — client-side routing works across all twenty routes, including the eight /admin screens, all of them running on empty stubs. Deep-linking and reloading a route 404s by design (there is no server behind this); use open full screen ↗ and the in-app nav. The seven documented deltas to the shell are in tripo3d-uk-mirror/MIRROR.md — no JS or CSS was edited, and the 49 chunks still hash to the origin manifest.

03 · The meter: 5 / 10 / 15

Every generation is priced in the site's own credits, and the number is baked into the frontend rather than returned by the API:

function H(W){return p.quad?"15 积分":O()?"10 积分":"5 积分"}chunk referenced by the entry bundle — credit cost per submit

The O() branch is the tell. It turns true when any of quad, forceSymmetry, flattenBottom, faceLimit, textureSize !== 4096 or textureFormat is touched — i.e. the local "5 / 10 / 15" tiers are Tripo's own add-on ladder (HD texture, HD geometry, quad mesh, advanced convert) re-priced, not a usage cost the operator measures.

User actionLocal creditsToggle that triggers it
Base generate5plain submit, default texture size
Texture / quality on10textureSize, textureFormat, faceLimit changed
Quad / symmetry / flatten15quad, forceSymmetry, flattenBottom
Export+N"导出 FBX（N 积分）" — per-format charge; GLB is the free one

The gate is client-side and absolute: if(balance < cost) → "积分不足 (需要 X，当前 Y)". Nothing generates without a positive balance, and balance only moves two ways: a generation, or an administrator typing a number into /admin/users (the panel reports "扣除成功 / 扣除失败", deduct succeeded / failed).

04 · The supply side is a pool of borrowed keys

/admin/keys is not a pricing page — it is a key farm. Its own copy says so:

管理 Tripo API Key，系统自动负载均衡调用 号池总余额: … 阈值: … · 自动补充: 已开启 / 已关闭 名称 | 余额 | 并发 | 优先级 | 调用/成功 | 状态 | 到期 | 操作 🤖 获取 Keyadmin chunk — key-pool console strings

Each row is an official Tripo API key with its own balance, concurrency cap, priority and expiry date. The pool has a floor of 6,000 credits and an auto-replenish switch — when the total drops below the threshold it fetches more keys. A separate /admin/subservers screen switches traffic mode between "仅主服务器 / 仅子服务器 / 主+子混合" (main only / sub only / mixed) and reloads the sub-server list, so the same upstream pool can be shared across several front-ends.

visitor → tripo3d.uk (Nuxt SPA, own login) → own credit balance ↓ /api/task (cost deducted client-side first) key pool [key A: bal, conc, prio, expiry] [key B: bal, conc, prio, expiry] ← auto-fetch below 6,000 [key C: …] ↓ developers.tripo3d.ai (1 credit = US$0.01, Stripe)

06 · Unit economics, computed

Upstream list prices are public, so the floor price of one local credit can be derived instead of guessed. Tripo's developer tier is 1 credit = US$0.01; H-series generation runs 10 credits (text→3D, no texture) to 30 (image→3D with standard texture). Against a 5-credit base charge:

Upstream callUpstream cr.Upstream US$Local cr.Break-even / local cr.
Text→3D, no texture10$0.105$0.020 · HK$0.16
Image→3D, no texture20$0.205$0.040 · HK$0.31
Image→3D + standard texture30$0.305$0.060 · HK$0.47
Quad retopo on top35$0.3515$0.023 · HK$0.18

So a local credit that sells for HK$0.50–1.00 (the usual band for these panels) is roughly 1.1×–6× the upstream cost on the base tier — healthy gross margin, and the quad/texture tiers are pure markup because they charge 2–3× the local credits for add-ons that cost Tripo $0.05–0.10. Note what is not in this column: the site publishes no price list and has no checkout, which is why the number you actually pay is settled in a chat window and not here.

The margin has one structural weakness, and it is the one the operator advertises. A shared pool lets them sell more credits than the pool can serve — that is the float. When the pool empties, the shortfall is not absorbed by the business, it is absorbed by whoever was mid-task. The announcement at the top of this page is that policy written down.

09 · What a buyer is actually buying

Not a licence — a balance. Credits are an unsecured prepayment recorded in a database owned by an unnamed operator on a four-month-old domain, redeemable only through keys they rent from Tripo and may lose at any time. The site's own banner states that when the pool empties, paid generations fail and are not refunded. Your account, prompts and uploaded images sit on their server, and their API sees all of it.

If the goal is cheap 3D models

  • Official tripo3d.com (Chinese) / tripo3d.ai — free tier, then Stripe credits at the same $0.01 list price the reseller buys at.
  • You keep the generations; nothing expires because someone else's pool ran dry.
  • No third party gets your prompts or your credential pair.

If the goal is understanding the genre

  • This is the shared-key arbitrage pattern: re-skin a vendor's app, meter it in your own currency, run a key pool, recurse into 分站.
  • The tell is always the same — no payment gateway in the build, an announcement about the backend account running out, and an admin screen full of upstream keys.
  • Cheap because the float is other people's money; fragile for exactly the same reason.

10 · Method

Fetched the shell, parsed its modulepreload hints, pulled all 49 referenced chunks (1.32 MB), grep'd the route table, the /api/ and /admin/ endpoint sets, credit-cost branches and every Chinese string literal in the admin chunks. Cross-checked registration and DNS against Nominet RDAP and whois.nic.uk, and upstream credit prices against developers.tripo3d.ai/en/pricing (read 2026-10-21: 1 credit = US$0.01; H-series 10/20/30). No account was created, no login attempted, no payment page exists to attempt.

Honesty notes. The operator's identity is not knowable from here: Cloudflare Registrar hides the registrant, and Nominet's own validation failed, so "who" is an open question, not a finding. The site publishes no price list — every HK$ figure above is a derived break-even floor from Tripo's public API prices, not a quoted retail price. The "号池 / 分流 / 分站" reading is from admin UI strings in the shipped bundle; I did not log in, so I have not seen the screens render, only the code and copy that build them. The evidence bundle keeps the served shell and the announcement response byte-identical; the vendor's application bundle is hashed but not republished — mirroring a live commercial app wholesale is not something this site should do.
