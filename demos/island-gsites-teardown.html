First finding: the link itself is not a site

https://sites.google.com/online.island.edu.hk returns HTTP 404 with an empty body. It is not a homepage — it is the namespace the school's Google Workspace publishes Sites into. Every real site hangs one path segment below it, like /maths or /questweek. So "how many" can only be answered by counting those segments, and Google will not hand you the list.

1 · Method — four sources, then one probe

No single source is complete, and each one lies in its own direction: the search index is shallow, the archive is stale, and on-site links only reach siblings someone bothered to link. So they were unioned and then every candidate was verified against the live host.

  1. Search index — site:sites.google.com/online.island.edu.hk paginated 30 pages deep. Gave 12 slugs before Google served a CAPTCHA and the crawl stopped itself. (595 indexed results reported)
  2. Wayback CDX — every capture of both the current /online.island.edu.hk/* and the legacy /a/online.island.edu.hk/* form. Gave 162 slugs and their page trees — the single biggest contribution.
  3. On-site links — crawling island.edu.hk, its sitemap, and the live Sites' own raw HTML surfaced is-experiential-learning, which neither index had.
  4. Live probe — all candidates fetched one by one and classified: real title + markup = public; redirect to accounts.google.com = gated. 11 vs 153. Zero false positives: every public row was re-checked with a plain curl and returned 200.

4 · The 153 that are not public

These all resolve, then bounce to a Google sign-in page: unpublished, restricted to the school domain, or deleted-but-still-routed. The archive says what most of them were — student project sites from roughly 2009–2013, back when Google Sites was the school's default publishing tool and every class produced a dozen /james-games-style pages.

What "gated" does and does not tell you

A sign-in redirect proves the path is still registered, not that the content survives behind it. Some are genuinely private course sites; many are simply unpublished student work that Google keeps routing. Reading them needs a @online.island.edu.hk session — which this investigation deliberately did not use.

5 · What this can't tell you (and why)

The honest limitation

164 is the number of paths visible from outside, not the number that exists. A Site that was never published, never linked, never crawled and never archived is invisible to all four sources — and Google Sites has no API that lists a domain's sites without Workspace admin rights. The real figure is ≥164. The complete list lives behind the Sites dashboard, not the open web.

Two more bounded claims worth stating plainly: the Google leg stopped at a CAPTCHA (30 pages, not the reported 595 results), and the archive leg only sees what the Wayback Machine happened to crawl — its newest captures here are thin, so a site published in the last few months could hinge entirely on the on-site-link and probe legs.

7 · What's next

  • Archive the 11 public sites properly — the language sites are the school's real teaching surface; a local mirror would survive a domain rename.
  • Ask the school for the Sites dashboard export — the only source that can turn ≥164 into an exact number.
  • Re-run the probe quarterly — the probe is stateless; the same four legs detect a new department site the week it appears.

Method. Google search paginated via a real Chrome instance over CDP (captcha-halted); Wayback CDX API over both URL forms; a plain-HTTP crawl of island.edu.hk and the Sites' nav markup; then 162 candidate paths probed directly, 3–4 concurrent, classified by final URL and title.
