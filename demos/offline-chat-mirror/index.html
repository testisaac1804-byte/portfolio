Run it

mkdir offline-chat && cd offline-chat
# put both .py files here, then:

python3 offline_chat_v2.py                 # http://<your-lan-ip>:9001
python3 offline_chat_v2.py --tls           # https, generated cert
python3 offline_chat_v2.py --password p    # room password
python3 offline_chat_v2.py --stealth       # port 443 + tls + password
python3 start_chat.py                      # guided launcher
Requirements: Python 3.9 or newer. Nothing else. No pip, no virtualenv, no npm. Standard library only — verified on Python 3.9.6 and 3.14, with and without openssl on the PATH.
This is a LAN chat. Every device has to be able to reach the host's IP: same WiFi, a phone hotspot, or a direct cable. It never opens an outbound connection, so it cannot span two different networks. The TLS certificate is self-signed — the browser warning is expected. Guest files are written to the host's uploads/ folder; there is no moderation beyond the host's delete button.
