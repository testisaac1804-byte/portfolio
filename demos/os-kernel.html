Hermes OS

A 32-bit x86 operating system kernel written from scratch — no libc, no host runtime, no framework. Boots under GRUB, sets up its own descriptor tables, services its own hardware interrupts, manages its own memory, and drops you into an interactive shell.

Boot flow

GRUB → multiboot header → _start (32-bit) → GDT → IDT → PIC remap → PIT 100 Hz → PS/2 keyboard → PMM + paging → filesystem → shell

Subsystems

Bootboot/boot.asm

Multiboot header, GRUB-loadable, enters 32-bit protected mode at 1 MB

GDTkernel/gdt.c

5 descriptors — null, ring-0 code/data, ring-3 code/data

IDTkernel/idt.c

256 gates: 32 CPU exceptions + 16 hardware IRQs

PICkernel/irq.c

8259A remapped to vectors 32–47, per-IRQ handler registry

Timerkernel/timer.c

PIT channel 0 at 100 Hz, tick counter driving uptime

Keyboardkernel/keyboard.c

Memorykernel/pmm.c

Three bugs that actually had to be debugged

The interrupt handler read garbage

Every IRQ is dispatched as irq_handler(registers_t*), but the assembly stub called irq_handler without pushing the frame pointer. The C code then read “int_no” out of whatever happened to be on the stack and indexed the handler table with it — a page fault at 0xc014d3d0, recursing until the stack hit an unmapped page and triple-faulted. Fix: push esp before the call in both the ISR and IRQ stubs.

Two bits of the PIC mask

0xFB looks like “enable IRQ0 and IRQ1” but the 8259A mask is inverted — 1 means masked. That value actually disabled both the timer and the keyboard. Correct mask: 0xFC.

The CPU slept through every keystroke

The idle loop used hlt, which only wakes on an interrupt. With IRQ0 and IRQ1 masked and the UART’s receive interrupt off, nothing ever woke it — so polled serial input was never read. Keeping the 100 Hz timer unmasked fixes it, and additionally required enabling the 8042 controller’s keyboard-interrupt bit (config byte bit 0) during init.

Build & run

# toolchain: nasm, clang (freestanding), x86_64-elf-ld, qemu
make                                  # → oskernel.elf (~37 KB)
qemu-system-i386 -kernel oskernel.elf -m 64

# headless, with the shell on your terminal:
qemu-system-i386 -kernel oskernel.elf -m 64 -serial stdio -display none
