SECTION 04共用基建指紋 — 一眼認出同一批人

① 老域名開路

218.com（1998）、213.com（1996）—— 品牌入口一定是多年老域名，內容一定在新域名上。老域名讓過濾器「看起來正常」。

② 同日批量註冊

同一個註冊商、同一分鐘、同一個 NS 對。這是「同一次操作」最硬的證據，比任何內容相似度都可靠。

③ 隨機子域名＋泛解析

8 位隨機字母前綴、17 位數字 www 前綴。目的是讓「封一個、長十個」成立。

④ 自建 NS 命名法

218 用 *cne.com 家族；213 用同一個 Cloudflare 帳戶。NS 是最難洗掉的指紋。

⑤ 假「瀏覽器」

「寰宇瀏覽器」、「chrome/firefox/quark/opera 下載頁」—— 全部是同一個 APK／側載包的包裝。

⑥ 真客服在人手 IM

網站上沒有真客服，只有 97chat／m2gnkr 聊天窗 → 真人接手 → 引導存款。這一步才是詐騙核心。

SECTION 08十條辨識紅旗（給任何人看）

  1. 域名很老，內容很新。1996／1998 年註冊的域名掛著 2025 年的賭場頁 —— 老域名只是門面。
  2. 網址由一堆隨機字母組成。yy2iaikt.213001.cc、www81019827016236468.2182999.com —— 正常人不會這樣命名。
  3. 一開始就是「Loading…」動畫。真正的加載不需要三秒假動畫；那是為了同時跑指紋腳本與跳轉。
  4. 問你要不要「下載專用瀏覽器」。沒有正規賭場需要你安裝一個自製瀏覽器。那是側載 APK 的包裝。
  5. 客服只在 97chat／Telegram／WhatsApp 出現。沒有工單系統、沒有公司地址、沒有牌照號。
  6. 網址裡有一串 ?agentName=。你在替某個代理賺佣金，那個人可能就是你群組裡「分享好康」的人。
  7. 有所謂「備用線路」清單。正規平台不需要每天換網址。
  8. 存款用 USDT／支付寶個人碼／「代付」。錢一進就無法追溯，也無法退款。
  9. 出金要先「打流水」或「審核」。 贏的錢永遠差一點才能拿。
  10. 頁面叫你關掉廣告攔截器或「網絡安全軟件」。它想繞過的就是唯一能保護你的東西。

過程中修正的兩個真問題

  1. 橫幅掉進擴充套件 template：儲存頁內有多個 </body>（MaxAI 之類的擴充把整個 HTML 塞進 <template>），用「第一個 </body>」插入會令橫幅落在不會渲染的 template 裡 —— HTML 原始碼搜得到、瀏覽器 DOM 卻不存在。改用最後一個 </body> 後才真正顯示（用 DOM 檢查驗證，不是 grep）。
  2. 兩個 session 同時部署：部署腳本寫死同一個 /tmp/isaac-site-bundle，同時跑會出現 rsync 檔尾截斷並在 wrangler 之前中止，而外層 | tail 仍回報 exit 0。已改為先偵測、等對方完成，並以 log 內出現 Deployment complete 為準。

「看似缺漏、實為原站缺陷」清單

  • 213 的 4 張 CSS 橫幅（/img/3edb81_700x125.png 等）在原站已經 404，五個候選路徑全部試過。
  • 218 的 FontAwesome 字型（/static/css/fonts/font-awesome-4.2.0/fonts/*）在原站全部 404 —— 原站的圖示字型根本沒部署成功。
  • 218 的 /api/hostnames 是頁面向自己網域發的請求，鏡像內自然沒有後端；已確認無外部連線。

為何不提供更「完整」的鏡像

登入後的會員區、存款頁、遊戲大廳需要真實帳號才能取得 —— 本調查沒有亦不會註冊、存款或下載任何執行檔。因此鏡像的邊界就是「未登入前可見的公開頁面」，這一點必須誠實標明，否則任何「100% 完整鏡像」的說法都是假的。
