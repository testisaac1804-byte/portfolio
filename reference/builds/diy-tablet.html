Step 1 — Flash Armbian

  1. Download Armbian for Orange Pi Zero 2W from armbian.com (or Zero 3 depending on board).
  2. Flash the SD card on macOS: 
    diskutil list
sudo dd if=~/Downloads/Armbian_*.img of=/dev/rdiskX bs=4m status=progress
  3. Insert card, plug in power, wait ~2 min for first boot.

Step 2 — First Login

Connect via micro-HDMI or SSH. Default password 1234 (it forces a change + creates a user).

ssh root@<ip-address>

Step 3 — Enable the TFT Screen

The screen talks SPI over the GPIO header:

TFT PinOrange Pi GPIO
VCCPin 1 (3.3V)
GNDPin 6 (GND)
CSPin 24 (SPI1 CS0)
RESETPin 22 (GPIO)
DC/RSPin 18 (GPIO)
SDI/MOSIPin 19 (SPI1 MOSI)
SCKPin 23 (SPI1 CLK)
LEDPin 1 (3.3V)
SDO/MISOPin 21 (SPI1 MISO)

Touch (XPT2046)

Touch PinOrange Pi GPIO
T_CSPin 26 (SPI1 CS1)
T_IRQPin 16 (GPIO)
T_DOPin 21 (SPI1 MISO)
T_DINPin 19 (SPI1 MOSI)
T_CLKPin 23 (SPI1 CLK)

Enable SPI

sudo armbian-config
# System → Hardware → enable spi-spidev
# then add overlay: spi-add-cs1   (touch needs its own CS)

Install the LCD driver (fbcp-ili9341)

sudo apt update
sudo apt install -y git build-essential device-tree-compiler

git clone https://github.com/juj/fbcp-ili9341.git
cd fbcp-ili9341 && mkdir build && cd build
cmake -DILI9486=ON -DSPI_BUS_CLOCK_DIVISOR=6 \
      -DGPIO_TFT_DATA_CONTROL=18 -DGPIO_TFT_RESET_PIN=22 ..
make -j4
sudo ./fbcp-ili9341

Auto-start on boot

Add to /etc/rc.local before exit 0:

/home/youruser/fbcp-ili9341/build/fbcp-ili9341 &

Step 4 — Lightweight Desktop

A full desktop crawls on 1GB RAM — use a window manager:

sudo apt install -y xorg openbox lightdm
sudo apt install -y xserver-xorg-input-evdev   # touchscreen driver
sudo apt install -y xinput-calibrator          # touch calibration

Step 5 — Make It Useful

✅ Works wellTerminal · file manager · text editor · SSH client · Python scripts · info display
⚠️ StrugglesYouTube/video · modern websites · multi-tasking (1GB RAM)

Or skip the desktop entirely

sudo apt install -y fbterm
# fbterm runs a terminal straight on the framebuffer — no X11 needed

Pitfalls

  1. Screen won't light up — check SPI is enabled in armbian-config, re-check wiring.
  2. Touch doesn't work — XPT2046 needs its own CS pin (CS1, not CS0).
  3. Board runs hot — Zero 2W is warm; a small heatsink helps (~5 HKD).
  4. Power bank auto-shuts off — many cut out at low current draw; test yours first.
  5. WiFi drops — onboard antenna is weak; fine within ~5m of the router.
Total: ~HK$100 for board + screen + power, assuming you already have a microSD and cable. Cheapest useful Linux computer you can build from Pinduoduo parts.
