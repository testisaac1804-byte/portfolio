# Isaac Trade — 萬用交易社群平台

A general-purpose trading community platform in Traditional Chinese.

## Categories (6)
🃏 卡牌 · 📦 實物 · 💾 數碼檔 · 🛠 服務 · 🌐 域名 · ✨ 其他

## Features
- **Anyone can post** — 賣 (sell) / 換 (trade) / 收 (want)
- **Comment offers** — negotiate in the thread, mark as 成交 (deal closed)
- **Author controls** — edit status or delete your own post with your 管理碼 (management code)
- **Admin** — delete any post with the admin password
- **Brand hub** in the header — Portfolio / IsaacDrop / Open Press
- Mobile-first UI

## Stack
Cloudflare Worker + KV (free tier) — no server to run, posts persist in KV.
