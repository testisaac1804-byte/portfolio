# Casio 2048 (fx-CG50)

The 2048 sliding-number puzzle compiled as a native add-in for the Casio fx-CG50 graphing calculator.

## What it is
- `.g3a` add-in — transfer via USB (fx-CG Manager / storage) or microSD
- Classic 2048: swipe to merge tiles, reach 2048
- Runs on the calculator's own hardware — no phone needed

## Files
- `Downloads/casio-games/2048.cg-50.g3a`
