# DAJA A6 Pro 20W Material Reference

LightBurn material settings reference for the **DAJA A6 Pro 20W blue diode laser** (455nm).

Single self-contained HTML page (light theme) covering:
- **Materials matrix** — speed/power settings for wood, acrylic, leather, cardboard, paper, slate, stone, glass, coated metals
- **Focus** — correct focal distance per material
- **Single-pass vs multi-pass** cutting strategy
- **Test grid** workflow — calibrate speed/power before a real cut
- **Banned / unsafe materials** — what NOT to engrave
- **Safety** — ventilation, fire watch, diode exposure

Ships as a standalone `.html` you can open directly in any browser (no server needed).
Image/settings values correspond to tested profiles in `~/Documents/Materials Reference.xlsx` (Sheet2).
