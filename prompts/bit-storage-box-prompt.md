# Bit Storage Box (CNC drill bits)

A 3D-printed storage box for CNC drill bits.

## What it is
- Base tray with sized holes to stand drill bits upright in the workshop
- Companion to the CNC Drill Box / Drill Bit Box family

## Files
- `Documents/common stl/bit-storage-box-base.stl`

## Design notes
- Fusion 360 design, printed on the Bambu Lab printer
