# VEX IQ Highrise Cube (2025–26 Game Element)

Isaac's own design iterations of the VEX IQ Highrise competition cube.

## What it is
- Recreations/iterations of the large Highrise game cube used in the 2025–26 VEX IQ challenge
- Multiple print iterations refining fit and detail

## Versions
- `HighRise_Cube.stl` — original
- `highrise cube original.stl` — clean master version
- `HighRise_Cube copy.stl` / `copy 2 2.stl` / `copy 3.stl` — design iteration 1 / 2 / 3
- `highrise cube v2 2.stl` — v2 final geometry
- `HighRise_Cube 2.stl` + `2.gcode` + `2.pwmb` — sliced print job
- `highrise cube text 2.dxf` — laser-cut logo/text plate (with `vex logo dxf/` logos)
