# Bambu Print Profiles Library

1946 official Bambu Lab profiles exported from Bambu Studio:

- **filament/** — PLA, PETG, ABS, ASA, TPU, PC, PA, CF variants, support materials (per-printer presets)
- **machine/** — printer definitions (X1, P1P/P1S, P2S, A1/A1 mini, H2D/H2C/H2S, X1E)
- **process/** — speed/quality process presets

## Use
Download the folder (or browse individual JSON files) and drop them into
Bambu Studio's profile directory — they are the stock official presets.
