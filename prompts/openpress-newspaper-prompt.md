# The Open Press — Community Newspaper

A newspaper written by anyone, for everyone:

- 8 sections: Local, World, Campus, Tech & Science, Sports, Arts & Culture, Opinion, Investigations
- Editorial rules enforced at write time: headline 5–90 chars, standfirst 10–60 words, 3–12 paragraphs, 300–900 words total, 1–4 images with alt + caption, optional pull quote, up to 5 tags
- Built on Cloudflare Workers + KV, single SPA client
