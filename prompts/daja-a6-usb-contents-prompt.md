# DAJA A6 Pro Official USB Contents

The complete official USB stick contents that ship with the DAJA A6 Pro 20W laser:

- **1.Windows / 2.MAC** — drivers (CH340 etc.)
- **3.APP / 4.Software_GRBL** — app code, LaserGRBL + LightBurn documentation
- **5.Firmware** — firmware + update guides (Windows/macOS)
- **8.Operation video** — official operation videos
- **6.Picture / 10.Photos** — design photos (E-art letters, paper-cut patterns, car logos, flowers, insects…)
- **7.UserManual**

Great for anyone re-installing the machine or looking for cut-pattern inspiration.
