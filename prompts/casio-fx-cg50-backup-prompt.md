# Casio fx-CG50 Backup (Add-ins + OS)

Official Casio fx-CG50 software, kept as a backup:

- **fx-CG50 add-ins.zip** — 3D Graph, Geometry, Physium, Convert add-ins + the official install guide
- **fx-cg50 OS update 3.80** — the G90-series system update

## Use
Drag the `.g3a` add-ins onto the calculator's storage (see the install guide), or
run the OS update from the second zip.
