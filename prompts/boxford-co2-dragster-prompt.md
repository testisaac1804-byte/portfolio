# Boxford CO₂ Dragster Manufacturing

CO₂ dragster (F1 in Schools) manufacturing pack for Boxford CNC equipment.

## Contents
- **`F1223 F1 BLANK.pdf`** + **`F1223 F1 BLANK V3.pdf`** — the F1 blank body drawing/blank layout
- **`Manufacturing Rtype Co2 Cars on Boxford Equipment.pdf`** — step-by-step machining process on Boxford machines
- **`R type F1 QuickCAM with SolidWorks, Solid Edge and ProD.pdf`** — CAM workflow for the R-type body
- **Jigs & fixtures** — `NewCo2Jig.des`, `Spigot.des`, `RtypeBlank.des`, `DesignRtype004.des`
- **`DesignRtype004.stl`** — printable R-type body model
- **`f1_model_block_18mm_v1.f3d`** — Fusion 360 model block (18 mm)
- **`CO2 Cart.swf`** — CO₂ cartridge reference

## Use
Everything needed to take a CO₂ dragster from blank to finished body: drawings, jig geometry for
holding the blank, the CAM toolpath workflow, and the Fusion model block for simulation.
