# Cookie Clicker (Casio PRIZM / fx-CG50)

A Cookie Clicker-style incremental game compiled as a `.g3a` add-in for Casio graphing calculators.

## What it is
- Click to bake cookies, buy upgrades, watch the counter climb
- Native calculator add-in (PRIZM / fx-CG50 family)
- `Downloads/casio-games/CookieClicker.g3a`

## Built with
Casio add-in toolchain (C), part of Isaac's calculator-game collection.
