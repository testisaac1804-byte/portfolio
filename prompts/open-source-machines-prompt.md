# Open-Source Machines Catalog

**Category:** Design & Documents · **Status:** Done

A curated catalog of **78 buildable open-source machines** — 3D printers, CNC routers/mills, lasers, lathes, EDM, wire benders, belt grinders and concrete printers — each with rough price, difficulty and build links.

**Stack / Tools:** Python generator → single-file HTML + JSON + Markdown · no deps · LIGHT theme

**Build path:**
- V1 — researched and catalogued 78 machines across 3D printing / CNC / other fabrication categories, with USD prices converted to HK$ at 7.8.
- V2 — added Chinese-sourcing notes (AliExpress / Pinduoduo / Taobao are typically 30–50% cheaper) and 中文 tutorial links (bilibili, FYSETC/LDO kits) wherever they exist.

**Location:** `~/Desktop/open-source-machines/` (published at `reference/machines/`)

**Fields per machine:** Machine · Origin · Price (USD) · Price (HK$) · Difficulty · "Why it's special" · Links (GitHub / docs / kits / video builds).

**Categories covered:** 3D printing (incl. hangprinter, chocolate printer, metal SLS/SLM), CNC (MPCNC, LowRider, PrintNC, Millennium Milo, Lasersaur, plasma tables, panel CNC), and small-shop machines.

**Notes:** Built around Isaac's real buying constraints — no credit card, Chinese sourcing, HK$ pricing. Every entry has a working link, and difficulty is rated Easy → Very Hard so the next build is a deliberate choice rather than an impulse.
