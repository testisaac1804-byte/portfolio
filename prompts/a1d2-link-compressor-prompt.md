# a1d2.org — Link Compressor

Compress long links and optimise QR codes entirely in the browser:

- Strips tracking/state query parameters to shorten URLs without breaking them
- QR-optimised output — no backend needed
- Bilingual (中文/EN) projects page at a1d2.org
- Based on the open-source ha.mr (MIT)
