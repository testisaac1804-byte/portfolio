# Economics - Market System Diagram Quiz (build spec)

**Deliverable:** one self-contained single-file HTML quiz at `reference/economics/Economics-Market-System-Diagram-Quiz.html`

**Board:** IGCSE Economics (Edexcel 4EC1), Unit 1.1.

## Content
Diagram-based questions with instant marking: PPF movement M -> N; supply curve shift S1 -> S2; PPF movement for a policy change; a subsidy shown on a demand/supply diagram; a draw-it question on raw material costs rising in the market for cars; and which PPC point is unobtainable. Closing panel: the two rules that crack every diagram question.

## Build rules
Dark theme, one self-contained HTML file, answer feedback per question, score tracking, no external assets.
