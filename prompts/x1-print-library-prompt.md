# X1 Bambu Print Library
Collection of 38 sliced print files produced on my Bambu X1 — exported as .gcode.3mf so each
file carries the full slice data (profiles, supports, plate).

## Contents
- Vase, Spartan SDCard Holder, Squishy Turtle, 3Dino Puzzle, BambuSpool, Phone Stand,
  Mini Tray, Film Sticking Fixture + 30 more
- Two plate variants: standard plate and textured PEI

- Local: `~/Downloads/X1-internal-sliced-files/` + `~/Downloads/internal-sliced-files-textured-plate-x1(texturedpei)/`
- Live: portfolio-files `x1 print library/`
