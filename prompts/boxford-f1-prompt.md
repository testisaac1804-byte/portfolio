# Boxford F1 (QuickCAM CNC)

F1 in Schools manufacturing files for the school's Boxford CNC router (QuickCAM workflow).

## What it is
- Boxford-design F1 blank and CO₂ car machining files:
  - `F1223 F1 BLANK V3.pdf` / `F1223 F1 BLANK.pdf` — blank drawings
  - `DesignRtype004.stl` / `RtypeBlank.des` — 3D design + Boxford .des job files
  - `NewCo2Jig.des`, `Spigot.des`, `CO2 Cart.swf` — CO₂ canister jig + spigot jobs
  - `Manufacturing Rtype Co2 Cars on Boxford Equipment.pdf` — full process guide
  - `f1_model_block_18mm_v1.f3d` — model block source
