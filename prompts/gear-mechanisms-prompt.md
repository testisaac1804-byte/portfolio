# Gear Mechanisms — 3D Print Set

Japanese mechanism model kits (機構模型プラスセット) — print and assemble working geared mechanisms.

## Contents
- **235 STL** parts + **8 3MF** print-ready plates + **8 ZIP** original archives
- Sets include: bevel gears (傘歯車), spur gear trains, rack & pinion, cam mechanisms, planetary sets, worm drives
- Per-set `Readme.txt` with assembly notes
- `齿轮40（1-20）.3mf` / `齿轮40（21-40）.3mf` — 40-tooth gear plates, both halves

## Use
Print on the Bambu X1, then assemble — good for teaching gear ratios, and as donors for CNC/laser mechanism projects.
