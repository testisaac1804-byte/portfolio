# Dino Game (Casio fx-CG50)

The offline Chrome dino-runner recreated as a native `.g3a` add-in for the Casio fx-CG50.

## What it is
- Jump the cacti, speed ramps up over time
- Pixel-art dinosaur on the calculator's display
- `Downloads/casio-games/dino.g3a`

## Built with
Casio fx-CG50 add-in toolchain (C), part of Isaac's calculator-game collection.
