# 茶寮 Fleur Tea — Online Shop

A complete live e-commerce site for a herbal flower-tea brand (天然無添加花草果茶・香港):

- **Storefront**: shop grid, product pages, quick-view, cart, coupons, search, blog, reviews
- **Admin panel**: products, orders, posts, coupons, reviews, layout, backups, dashboard
- **Tech**: Cloudflare Worker + KV, single-worker SPA + JSON API, validation rules
- **Verified**: acceptance / cart / coupons / features / SEO test suites
