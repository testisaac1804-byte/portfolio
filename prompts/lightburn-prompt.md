# LightBurn Isaac Libraries

Custom LightBurn libraries built by Isaac for the DAJA A6 Pro 20W laser.

## What it is
- `ArtLibrary-Isaac.lbart` — personal laser-art library (reusable artwork)
- `Isaac Material Library.clb` — custom material settings (speed/power matrix)
- `Isaac Engrave Library.clb` — engrave-focused settings library
