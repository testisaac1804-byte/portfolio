# 5-Axis Desktop CNC Model (RAPIMA RMX-15)

Full CAD reference model of a RAPIMA RMX-15 5-axis desktop CNC machining centre.

## Contents
- **538 SolidWorks parts** (`.sldprt`) + master assembly (`.sldasm`)
- `RAPIMA,RMX-15.STEP` — universal STEP export of the whole machine (49 MB)
- `RAPIMA,RMX-15.zip` — original archive (62 MB)
- Photos of the machine

## Use
Reference for 5-axis kinematics, trunnion/rotary table layout, ballscrew and linear-rail packaging. Useful when designing fixtures or planning desktop CNC upgrades.
