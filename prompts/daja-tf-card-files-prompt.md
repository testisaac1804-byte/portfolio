# DAJA A6 Pro TF Card Files

The complete TF-card contents that ship in the DAJA A6 Pro 20W laser engraver.

## Contents
- **345 JPG + 124 PNG + 3 GIF** — sample artwork, material test photos, laser result references
- **8 PDF** — machine and software documentation
- **3 EXE + 2 BIN** — Windows software and firmware images
- **1 XLSX** — settings/material table

## Use
Sample material photos are handy for judging what a 20W diode can do on wood, acrylic, leather and coated metal before you commit a real piece. Pairs with the DAJA A6 Pro USB contents and the laser settings library.
