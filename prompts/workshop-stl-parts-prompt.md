# Workshop STL Parts Library

A working collection of practical 3D-printable parts I reuse across projects.

## Contents
- **Vise jaws** — 80 mm magnetic jaw (test + press-fit final), magnet-in inside variants
- **Adapters** — 3 mm hex adapter, hex adapter v4, USB-C to USB adapter (v1/v2)
- **Plugs & caps** — 1205 / 608 bearing plugs, tight 1205 plug, USB dust cover
- **Storage** — bit storage box base, Bravo Prodigy CNC bit case, big bowl clicker base
- **Misc** — inner hex screw, and other shop odds and ends

## Use
Print as needed for jigs, adapters and storage. Each part has been test-fitted; the `.3mf` variants
are the sliced/plate versions for the Bambu X1.
